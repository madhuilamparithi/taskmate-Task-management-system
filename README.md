
# TaskMate – Task Management System

## 1. Project Overview
TaskMate is a task management application designed to help users organize tasks, set deadlines, prioritize activities, and track task completion.

## 2. Objectives
- Organize daily tasks efficiently.
- Set task priorities and due dates.
- Track pending and completed tasks.
- Improve time management and productivity.

## 3. Project Scope
TaskMate includes task creation, editing, deletion, task status tracking, calendar scheduling, and profile settings.

## 4. Main Features
- Login and Sign Up
- Dashboard
- My Tasks
- Add/Edit Task
- Calendar
- Profile and Settings

## 5. SDLC Model
We follow the Agile SDLC model to develop the application in small stages, test features, collect feedback, and improve the product.

## 6. Technologies Used
- Frontend: HTML, CSS, JavaScript
- Version Control: Git and GitHub

## 7. Team Responsibilities
1. Project Manager and Documentation
2. Requirements and User Stories
3. SDLC, Workflow and Wireframe
4. Prototype Development
5. Testing and Defect Report
6. Integration and Presentation

## 8. Testing
The application will be tested for login validation, task creation, task editing, task deletion, task completion, and calendar display.

## 9. Expected Outcome
A user-friendly task management application that helps users plan, organize, and monitor their daily activities.

## 10. Conclusion
TaskMate aims to make task management simpler through an organized interface and effective task tracking.
